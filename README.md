# TrustGig

Hire vetted professionals you can trust.

## Stack
- Next.js 13
- Tailwind CSS
- Supabase (optional auth)

## Deploy on Vercel
1. Import this GitHub repo in Vercel
2. Framework: Next.js (auto-detected)
3. Root Directory: leave as `.` (repo root)
4. Deploy

## Local
```bash
npm install
npm run dev
```
